# Bâtiments réservés aux gnomes

`gnome-tower.png` est le PNG original `Enemy Pack/Extra/Gnome Buildings/Gnome Tower.png`, fourni par l’utilisateur avec Tiny Swords (Enemy Pack).

À sa demande, cette tour champignon est réservée aux gnomes. Ne pas l’utiliser pour les imps ou une autre créature. Elle n’est pas incluse dans le site distribué tant que les gnomes n’ont pas leur bâtiment en jeu.
